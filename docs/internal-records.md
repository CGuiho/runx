# Internal records

The complete internal lifecycle records for this project — plans, question
ledgers, review handoffs, validation evidence and the completed-task archive —
live in the private GUIHO repository `CGuiho/guiho`, under `docs/projects/runx/`.

Agents working on this project must read them there; they are not duplicated
here because this repository is public.

| Record | Location in `CGuiho/guiho` |
| --- | --- |
| Implementation plans and worker handoffs | `docs/projects/runx/plans/` |
| DND question ledgers | `docs/projects/runx/questions/` |
| Review handoffs and human reviews | `docs/projects/runx/reviews/` |
| Validation evidence | `docs/projects/runx/validation/` |
| Brainstorm records | `docs/projects/runx/brainstorm/` |
| Completed-task archive | `docs/projects/runx/todo/done/` |

What remains in this repository is user-facing: the requirements, architecture,
decision and reference documentation, the open task specifications under
[`docs/todo/`](todo/), the changelog and the task mirror [`TODO.md`](../TODO.md).
The task list itself stays authoritative in the bound GitHub Project; `TODO.md`
mirrors it.
